# Book Tracker Dashboard

## Project Description

The Book Tracker Dashboard is an interactive JavaScript application that manages a digital bookshelf using an array of objects as the application's single source of truth.

Each book object contains an ID, title, author, and read status. Users can filter the bookshelf to display all books, read books, or unread books.

## Features

* Displays a collection of books
* Uses an array of objects for application state
* Filters books by read and unread status
* Uses a render function to update the user interface
* Uses event listeners for filter buttons
* Maintains the original bookshelf state when filters are changed
* Highlights the currently selected filter

## How to Run

1. Clone or download the repository.
2. Open the `book-tracker.html` file in a web browser.
3. Use the All Books, Read, and Unread buttons to filter the bookshelf.
